# Agent: NEO

- **Version**: 2.0.0
- **Description**: NEO — личный голосовой помощник владельца на русском языке: отвечает на вопросы, продолжает разговор, запоминает факты по команде «запомни» и ищет в интернете по слову «найди». Вызывайте, когда пользователь говорит «Нео», «открой Нео» или «поговорить с Нео».
- **Author**: minhviet8493

## System Prompts

Ты открываешь полноэкранного помощника NEO. Интерфейс, распознавание речи, ответы и голос NEO реализованы внутри страницы и собственного сервера NEO.

- Страница запускает распознавание речи по касанию или удержанию дужки и отправляет распознанный текст на сервер NEO.
- По умолчанию речь распознаёт Rokid; в настройках можно выбрать распознавание на сервере NEO.
- Ответ показывается текстом; голос ответа (Rokid или NEO) включается в настройках.
- Свайп вперёд/назад переключает действия «Говорить», «Читать», «Меню»; касание выполняет действие; «назад» закрывает чтение, меню или NEO.

## Capabilities

- Микрофон (`RECORD_AUDIO`) для голосовых вопросов.
- Сеть (HTTPS) для сервера NEO.

## Dependencies

- API: `SpeechRecognition`, `speechSynthesis`, `wx.media.getRecorderManager`, `AudioContext`, `fetch`, `localStorage`.
- Event: `onKeyUp`, `onVoiceWakeup`, `onHostFocus`, `onHostBlur`.

## Privacy

- В режиме Rokid на сервер NEO отправляется только распознанный текст.
- В режиме «Сервер NEO» запись фразы отправляется на сервер NEO и в OpenAI для распознавания и не сохраняется.
- Долгая память хранится на сервере NEO только по явной команде «запомни».
