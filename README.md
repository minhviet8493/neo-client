# NEO — личный помощник для Rokid Glasses

Полноэкранный AIUI-агент: микрофон очков записывает вопрос, сервер NEO распознаёт речь и сразу
отвечает потоком, ответ читается системным голосом Rokid. Сервер — отдельный репозиторий
`neo-core` (`https://neo-core.1click24.ru`). Системное распознавание Rokid не используется:
на прошивке AIUI 0.17 оно не понимает русский.

Корень репозитория — это и есть пакет агента (`AGENTS.md`, `app.json`, `app.js`, `pages/`),
поэтому Craft может импортировать репозиторий целиком: Import → GitHub → ссылка. Всё остальное
(`tests/`, `tools/`, документация) в пакет не попадает: см. `.aixignore`.

## Доступ: подтверждение в Telegram

В репозитории нет ни одного секрета. Пока доступа нет, первая кнопка называется
**«Подключить»**: сам по себе NEO ничего никуда не отправляет. По нажатию очки показывают
четырёхзначный код, а владельцу приходит сообщение в Telegram-бот NEO с этим же кодом и
кнопками «Подтвердить» / «Отклонить». Пока владелец не нажал «Подтвердить», NEO не отвечает
на вопросы и не тратит деньги.

- подтверждение запоминается (`neo.access.v1` в памяти очков) и больше не спрашивается, пока
  не сменится версия сборки или не пройдёт 30 дней;
- отклонение, истёкший запрос и потерянное подтверждение снимаются одним касанием «Говорить» —
  придёт новый запрос;
- «Отклонить» в боте, команда `/stop` или новая сборка закрывают доступ немедленно;
- в боте: `/start` — привязать чат владельца (первый написавший становится владельцем),
  `/status` — расходы за месяц, `/stop` — снять привязку и отозвать доступ всех устройств.

Настройка на стороне сервера — `docs/deployment.md` в репозитории `neo-core`.

## Обновление на очках

1. Craft: Import → GitHub (или Sync, если проект уже подключён); либо открыть локальную папку.
2. Run Agent: появляется лента разговора и персонаж внизу.
3. Studio / Build & Review: разрешения Network и Microphone → Save Details → Package AIX.
4. Приложение Rokid → Настройки → Developer → AIUI → обновить ресурсы очков.
5. На очках полностью закрыть NEO и открыть снова.
6. После обновления сборки нажать «Подтвердить» в Telegram.

Собрать пакет локально: `cd tools/ink-preview && npm install && npm run pack` →
`dist/neo-glasses.aix`; Craft умеет импортировать `.aix` напрямую.

## Экран

- Вся высота — лента разговора: вопрос 12 px тусклый, ответ 16 px яркий, между репликами отступ.
- Ответ приходит потоком: первые слова видны через ~1–2 с, дальше текст дописывается, а когда
  ответ готов — стоит целиком. Озвучка идёт своим темпом и текст не задерживает.
- Справа тонкая полоска прокрутки: высота бегунка показывает, какая часть разговора видна.
- Внизу слева персонаж 32 px: моргает, ореол растёт с громкостью при приёме, рот двигается при
  озвучке; рядом одно слово состояния («слушаю», «думаю», «говорю», «пауза»).
- Справа кнопки **Говорить** и **Меню**: выделенная подсвечена, нажатие мигает. Без доступа
  первая кнопка называется **Подключить**, во время ожидания подтверждения — **Ждём…**.
- Строка текста над кнопками появляется только при ошибке или предупреждении о бюджете.
- Лента хранит весь сеанс (до 20 пар) в памяти очков; «Новый разговор» её очищает.

## Управление

Жесты очков (AIUI 0.17, измерено по телеметрии): свайп = `GlobalHook`, через 100–200 мс пара
стрелок (`ArrowRight`+`ArrowDown` вперёд, `ArrowLeft`+`ArrowUp` назад); касание = `GlobalHook`,
через ~500 мс `Enter`. Поэтому каждый `GlobalHook` открывает жест: первая стрелка после него —
один шаг, парная игнорируется; если за 350 мс стрелки нет — это касание. Повторное касание в
пределах 0,7 с считается эхом того же жеста, системная навигация подавлена. Craft присылает
стрелки и `Enter` без `GlobalHook` — это тоже работает.

- Свайп листает ленту по три строки; «▲ выше ещё N» и «▼ ниже ещё N» показывают скрытое.
- Свайп вперёд в конце ленты выделяет «Меню», свайп назад возвращает к ленте.
- Касание выполняет выделенное действие; удержание дужки сразу начинает разговор.
- «Назад» закрывает меню и проверки, на главном экране — закрывает NEO.

## Как проходит вопрос

0. При первом запуске (и после обновления) — «Подключить» и подтверждение в Telegram.
1. Касание (или удержание дужки) включает запись.
2. Пауза 0,8 с завершает фразу; тишина вокруг не отправляется, звук приводится к 16 кГц.
3. Один запрос `POST /v1/ask`: события `transcript` → `delta` … → `done`.
4. Ответ читается системным голосом Rokid (если голос включён); на время ответа запись на паузе,
   чтобы очки не глушили динамик и ответ не попал в микрофон как новый вопрос.
5. **Непрерывный разговор** (по умолчанию): после ответа NEO слушает снова; 10 с тишины — пауза.
   В режиме «по касанию» ход заканчивается ответом.

Интернет доступен модели всегда: она сама решает, искать ли (погода, новости, цены, расписания).

## Голосовые команды

- «Запомни: …», «покажи память», «забудь номер 1», «забудь всё» — долгая память на сервере.
- «Новый разговор» — сбросить контекст (факты остаются).
- «Стоп», «хватит», «пауза» — пауза.
- «Подумай …», «объясни подробно …» — ответ более сильной моделью, в ленте помечается
  «· глубокий ответ».

## Меню

**Настройки:** Голос ответа (включён / выключен) · Разговор (непрерывный / по касанию) ·
Микрофон (обычный / тихая речь) · Новый разговор · Показать память · Сервис › · Готово.

**Сервис:** Тест микрофона · Проверка устройства · Переподключить · ‹ Назад.

Списки не прокручиваются по кругу: на краю в заголовке «▲ начало» / «▼ конец».

## Самовосстановление

- Нет связи при запуске — повтор через 5, 15 и 30 с.
- Потерянный запрос повторяется один раз; истёкший доступ продлевается незаметно.
- Шум, который сервер не распознал, не прерывает разговор.
- Микрофон замолчал дольше 4 с при приёме — NEO сообщает об этом.

## Телеметрия

Очки отправляют на сервер (`POST /v1/diagnostics`, Bearer, до 20 событий раз в 8 секунд) только
технические коды: нажатия (тип, клавиша, интервал), фазы, события и ошибки распознавания, число
аудиокадров и пиковый уровень, длину распознанного текста. Текст вопросов и ответов не
отправляется, русские тексты ошибок транслитерируются; сервер отклоняет всё, кроме
`[A-Za-z0-9_.:+- ]`. Смотреть на сервере:
`docker compose exec backend grep client_event /app/logs/neo.log | tail -50`.

## Модели и расходы (на стороне сервера)

| Задача | Модель | Цена OpenAI (17.09.2026) |
| --- | --- | --- |
| Обычный ответ | `gpt-5.6-luna` | $0.20 / $1.20 за 1M токенов |
| «Подумай / подробно» | `gpt-5.6-terra` | $2 / $12 за 1M токенов |
| Поиск в интернете | web search | $10 за 1000 поисков, когда модель решает искать |
| Распознавание | `gpt-4o-mini-transcribe` | $0.003 / мин |
| Голос ответа | системный Rokid | бесплатно |

Месячный лимит задаётся на сервере (`NEO_MONTHLY_BUDGET_USD`, сейчас $100): после 80% NEO
предупреждает, при исчерпании отказывает.

## Проверки

```bash
node --test tests/page.test.cjs                        # логика страницы в Ink-подобной среде
cd tools/ink-preview && npm install && npm run pack    # -> dist/neo-glasses.aix
./run.sh dist/neo-glasses.aix out/check wait:2500 shot:idle key:Enter wait:1000 shot:talk
```

`run.sh` отрисовывает пакет в настоящем рантайме Ink (wasm) в Docker-образе Playwright с
подменённым сервером, пишет скриншоты и печатает консоль страницы. Клавиши: `Enter` — касание,
`ArrowUp`/`ArrowDown`/`ArrowLeft`/`ArrowRight` — свайпы, `GlobalHook` — касание дужки,
`Backspace` — назад. `MOCK=long|huge` возвращает длинные ответы, `MOCK=pair` оставляет экран
подтверждения (кнопку в боте никто не нажимает).

Веб-хост не умеет распознавать и синтезировать речь, поэтому голос проверяется только тестами с
подменами и на самих очках.

## Особенности рантайма Ink (проверено в настоящем рантайме)

- `clearTimeout(undefined)` бросает исключение — только `stopTimer()`.
- `<text>` не выводит переводы строк, контейнеры не обрезают переполнение — текст переносится в
  JS и выводится окном строк.
- Inline `transform` делает элемент невидимым — анимация через размеры, отступы и прозрачность.
- `word-break`, `white-space`, `overflow`, `animation` в WXSS не поддерживаются.
- `fetch` требует объект `headers`; `crypto.randomUUID` отсутствует.
- Статический `import` отсутствующего модуля ломает страницу — `wx` и токен загружаются лениво.
- `setData` обновляет `this.data` сразу, но частые вызовы придерживаются: один `setData` на кадр.

репозитории `neo-core`.
